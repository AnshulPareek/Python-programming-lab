- Object-Oriented Programming
- Exception Handling

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/AnshulPareek/Python-Programming-Lab.git
```

2. Navigate to the desired lab directory.

3. Execute a Python program:

```bash
python filename.py
```

Alternatively:

```bash
python3 filename.py
```
